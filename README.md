# INFINITO GROUP Website

*Global Vision, Infinite Opportunities.*

Homepage design preview (static HTML/CSS/JS) for INFINITO GROUP. This is the approved visual reference; the production site is built on **WordPress** (see `docs/MASTER-PROMPT.md`).

## Structure
```
index.html              Homepage
assets/css/style.css    Styles (brand tokens in :root)
assets/js/main.js       Form preview behaviour
assets/images/          Logo and approved imagery
docs/MASTER-PROMPT.md   Rules + master prompt for the WordPress build
```

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy on GitHub Pages
Repo Settings > Pages > Source: `main` branch, `/ (root)`.
